# YouTube In-Player Controller

YouTubeの再生画面内に直接、シーク（時間調整）や再生速度の微調整を行えるパネルを追加するChrome拡張機能です。
最新Ver 1.4

## 特徴
- 0.1秒単位のスムーズシーク
- 0.01倍単位の再生速度調整
- 自動ループ再生機能
- YouTubeのプレイヤーに直接UIを統合

## インストール方法
Chromeウェブストアを経由しないため、以下の手順で手動インストールをお願いします。

1. このページの右上にある緑色の「Code」ボタンをクリックし、「Download ZIP」を選択して保存・解凍します。右側のRelease欄からもDLできます
2. 拡張機能の管理画面を開きます。(ChromeのURLバーに `chrome://extensions/` と入力するか、右上のメニューから「拡張機能→拡張機能を管理」を開く)
3. 画面右上の **「デベロッパーモード」** のスイッチをオンにします。
4. 左上に現れる **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダ（`manifest.json` が入っているフォルダ）を選択します。
5. YouTubeを開き、動画にマウスを乗せると下部にコントローラーが表示されます。

## YouTube In-Player Controllerの使い方 (v1.4)

プレイヤーに表示されるパネルから各種操作を行います。

### 1段目：時間調整 (Adjust)
- **▶ / ⏸**：動画の再生・一時停止を切り替えます。
- **|◀**：動画の最初（0秒）に戻ります。
- **シークボタン**：指定した秒数（±5秒、±1秒、±0.1秒）だけ動画を移動します。

### 2段目：速度・全体ループ
- **Speed**：ボタン（±0.01）またはスライダーで、再生速度を0.1倍〜4.0倍の間で調整できます。スライダー上にカーソルを合わせ、マウスホイールを回転させることでも微調整が可能です。
- **Reset**：再生速度を1.00倍に戻します。
- **Loop: ON/OFF**：動画全体のループ再生を切り替えます。再生リスト経由で開いた動画でも、次の動画へ進まずにループが維持されます。

### 3段目：A-B Loop / HOT CUE
※この段は設定画面から非表示にすることができます。

- **A-B Loop（部分ループ）**
  - **In**：ループの開始位置を設定します。
  - **Out**：ループの終了位置を設定します。
  - **+◯s**：現在地から指定した秒数間（初期設定は10秒）のループを即座に設定します。
  - **Clear**：ループ設定を解除します。
- **HOT CUE（ポイント記憶）**
  - 動画内の特定の再生位置を3か所まで記憶し、瞬時にジャンプできる機能です。
  - **ジャンプ**：登録済みのボタンをクリック、またはキーボードの `Q` `W` `E` を押します。
  - **記憶**：未登録のボタンをクリック、または `Shift` + `Q / W / E` を押します。
  - **削除（リセット）**：登録済みのボタンを右クリック、または `Shift` + 登録済みのキーを押します。

## 設定メニュー

ブラウザ右上の拡張機能アイコンから本機能をクリックすると、設定画面が開きます。設定値は操作した瞬間に自動で保存・反映されます。スライダーはマウスホイールでの操作にも対応しています。

- **拡張機能を有効にする**：拡張機能全体のON/OFFを切り替えます。
- **UIの高さ**：パネルの表示位置（高さ）を0〜100の間で調整します。
- **UIの透明度**：パネルの透明度を調整します。
- **A-B Loop / HOT CUE (3列目) を表示**：3段目パネルの表示/非表示を切り替えます。
- **即時ループの間隔**：A-B Loopの「+◯s」ボタンでループする秒数を設定します。
- **ニコニコ動画でもUIを表示**：ニコニコ動画での動作を有効にします（※サイト側の仕様によりシーク同期などに不具合が出るため、初期設定はOFFです）。
- **最新アップデートを確認**：新しいバージョンが公開されているかを確認し、更新がある場合はダウンロードページへのリンクを表示します。

## その他の仕様
- **レスポンシブ対応**：ブラウザやプレイヤーのウィンドウサイズを縮小すると、パネルが自動的にコンパクトなレイアウトに切り替わり、画面外にはみ出さないよう自動調整されます。
- **データのリセット**：別の動画に遷移すると、ループ設定およびHOT CUEの記憶データは自動的にリセットされます。
